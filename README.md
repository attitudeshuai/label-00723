# 医院设备管理系统

基于 Web 的医院设备全生命周期管理平台，纯前端实现，使用 localStorage 存储数据。

## 快速启动

```bash
# 启动服务
docker-compose up --build -d

# 查看状态
docker-compose ps

# 停止服务
docker-compose down
```

## 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 管理后台 | http://localhost:8081 | 设备管理、报表查询 |
| 用户端 | http://localhost:8082 | 设备查询、报修提交 |

## 测试账号

| 用户名 | 密码 | 角色 | 权限 |
|--------|------|------|------|
| admin | admin123 | 管理员 | 全部功能 |
| user | user123 | 普通用户 | 查询、报修 |

## 功能模块

### 管理后台
- 设备分类管理
- 设备字典维护
- 设备入库/出库
- 设备折旧计算
- 设备报废处理
- 设备维修管理
- 多维度报表查询

### 用户端
- 设备概览统计
- 我的设备查询
- 设备报修提交
- 报修记录查看

## 技术栈

- 前端框架: HTML5 + CSS3 + JavaScript (原生ES6+)
- 图表绑制: Canvas API (饼图、柱状图)
- 数据存储: localStorage (浏览器本地存储)
- 样式特性: CSS3 变量、Flexbox、Grid、动画过渡
- 响应式设计: 媒体查询适配手机/平板/桌面
- 容器化部署: Docker + Nginx
- 无外部依赖: 纯原生实现，无需第三方库
