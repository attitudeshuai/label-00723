# 医院设备管理系统

## How to Run

```bash
# 克隆项目后，在根目录执行
docker-compose up --build -d

# 查看运行状态
docker-compose ps

# 停止服务
docker-compose down
```

## Services

| 服务名称 | 端口 | 说明 |
|---------|------|------|
| frontend-admin | 8081 | 管理后台 |
| frontend-user | 8082 | 用户端 |

## 项目介绍

医院设备管理系统是一个基于Web的设备全生命周期管理平台，支持设备从入库、使用、维修、折旧到报废的完整流程管理。

### 功能特性

- **设备字典管理**: 支持设备分类、品牌、型号等基础数据维护
- **设备入库管理**: 完整的入库单据流程，自动更新库存
- **设备出库管理**: 支持按科室出库，库存实时更新
- **设备折旧管理**: 支持自动折旧计算和手动调整
- **设备报废管理**: 报废审批流程，库存自动清零
- **设备维修管理**: 维修工单管理，状态实时跟踪
- **报表系统**: 多维度报表查询，支持数据导出

### 技术架构

- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **后端**: Node.js + Express
- **数据存储**: 内存存储 (演示用)
- **容器化**: Docker + Docker Compose
